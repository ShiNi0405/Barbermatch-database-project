## 1.0 Introduction

### 1.1 Project Overview
BarberMatch is a comprehensive database system designed to revolutionize the barbershop industry by providing a centralized platform for connecting customers with local barbers. The system addresses critical challenges in the current manual booking processes while creating a transparent marketplace for barber services.

### 1.2 Project Significance
The barbershop industry, particularly individual barbers and small establishments, faces significant operational challenges including manual booking processes, scheduling conflicts, limited online presence, and inefficient customer-barber matching. BarberMatch aims to solve these problems through a modern, database-driven solution.

### 1.3 Project Scope
This database project focuses on creating a robust, scalable system that manages user accounts, barber profiles, service offerings, appointment scheduling, customer reviews, and portfolio management. The system will serve as the foundation for a mobile application that connects customers with barbers in their local area.

## 8.0 Requirement Analysis (AS-IS System, Functional & Non-Functional)

### 8.1 Current Business Process (Scenarios + Workflow)

#### 8.1.1 Current Booking Process (AS-IS)
**Scenario:** Customer wants to book a haircut appointment

**Current Workflow:**
1. **Customer Contact:** Customer calls barber or sends WhatsApp message
2. **Manual Response:** Barber manually checks availability
3. **Manual Entry:** Barber writes appointment in notebook or calendar
4. **Manual Confirmation:** Barber calls customer to confirm
5. **Manual Reminder:** Barber manually calls customer 1 day before appointment
6. **Manual Tracking:** Barber manually tracks completed appointments

**Problems Identified:**
- Time-consuming process (15-20 minutes per booking)
- High risk of double booking
- No centralized record keeping
- Manual reminder system often fails
- No customer history or preferences

#### 8.1.2 Current Service Management (AS-IS)
**Scenario:** Barber wants to update service prices

**Current Workflow:**
1. **Manual Update:** Barber manually updates price list
2. **Manual Communication:** Barber informs customers of price changes
3. **Manual Record:** Barber updates personal records
4. **Manual Display:** Barber updates physical price board

**Problems Identified:**
- Inconsistent pricing information
- No centralized service catalog
- Difficult to track service performance
- Manual communication errors

## 9.0 Transaction Requirements (Entry, Update/Delete, Queries)

### 9.1 Data Entry Operations (INSERT)

#### 9.1.1 User Management Operations
- **INSERT_USER:** Create new user account
- **INSERT_BARBER_PROFILE:** Create barber business profile
- **INSERT_CUSTOMER_PROFILE:** Create customer profile
- **INSERT_USER_PREFERENCES:** Set user preferences

#### 9.1.2 Service Management Operations
- **INSERT_SERVICE:** Add new service offering
- **INSERT_SERVICE_CATEGORY:** Create service category
- **INSERT_SERVICE_PRICE:** Set service pricing
- **INSERT_SERVICE_AVAILABILITY:** Set service availability

#### 9.1.3 Appointment Operations
- **INSERT_APPOINTMENT:** Create new appointment booking
- **INSERT_APPOINTMENT_NOTES:** Add appointment notes
- **INSERT_APPOINTMENT_REMINDER:** Schedule appointment reminder
- **INSERT_APPOINTMENT_HISTORY:** Record appointment history

#### 9.1.4 Review Operations
- **INSERT_REVIEW:** Submit customer review
- **INSERT_RATING:** Rate barber or service
- **INSERT_REVIEW_COMMENT:** Add review comment
- **INSERT_REVIEW_FLAG:** Flag inappropriate review

### 9.2 Data Update/Delete Operations (UPDATE/DELETE)

#### 9.2.1 Profile Management Operations
- **UPDATE_USER_PROFILE:** Modify user information
- **UPDATE_BARBER_PROFILE:** Update barber business information
- **UPDATE_SERVICE_DETAILS:** Modify service information
- **UPDATE_APPOINTMENT_STATUS:** Change appointment status

#### 9.2.2 Status Management Operations
- **CONFIRM_APPOINTMENT:** Confirm appointment booking
- **CANCEL_APPOINTMENT:** Cancel appointment
- **RESCHEDULE_APPOINTMENT:** Reschedule appointment
- **COMPLETE_APPOINTMENT:** Mark appointment as completed

#### 9.2.3 Data Management Operations
- **SOFT_DELETE_USER:** Deactivate user account
- **SOFT_DELETE_SERVICE:** Deactivate service
- **DELETE_APPOINTMENT:** Remove appointment
- **DELETE_REVIEW:** Remove inappropriate review

### 9.3 Data Query Operations (SELECT)

#### 9.3.1 User Queries
- **GET_USER_BY_ID:** Retrieve user by ID
- **GET_USER_BY_EMAIL:** Retrieve user by email
- **GET_USER_PROFILE:** Get complete user profile
- **GET_USER_APPOINTMENTS:** Get user appointment history

#### 9.3.2 Barber Queries
- **GET_BARBER_BY_LOCATION:** Find barbers by location
- **GET_BARBER_SERVICES:** Get barber service list
- **GET_BARBER_AVAILABILITY:** Check barber availability
- **GET_BARBER_REVIEWS:** Get barber reviews and ratings

#### 9.3.3 Service Queries
- **SEARCH_SERVICES:** Search for services
- **FILTER_SERVICES_BY_PRICE:** Filter services by price range
- **FILTER_SERVICES_BY_CATEGORY:** Filter services by category
- **GET_SERVICE_DETAILS:** Get detailed service information

#### 9.3.4 Appointment Queries
- **GET_APPOINTMENTS_BY_DATE:** Get appointments for specific date
- **GET_APPOINTMENTS_BY_STATUS:** Filter appointments by status
- **GET_APPOINTMENT_HISTORY:** Get appointment history
- **CHECK_AVAILABILITY:** Check time slot availability

#### 9.3.5 Reporting Queries
- **GET_BARBER_STATISTICS:** Get barber performance metrics
- **GET_REVENUE_REPORT:** Generate revenue reports
- **GET_CUSTOMER_ANALYTICS:** Analyze customer behavior
- **GET_POPULAR_SERVICES:** Identify popular services
